# Task Manager

A simple task manager built with Next.js, React, and JavaScript.

This project was created as a beginner-friendly front-end project. The goal is to practice React components, state, events, lists, conditional rendering, and browser storage.

## Features

- Add a new task.
- Mark a task as completed or pending.
- Edit an existing task.
- Delete a task.
- Filter tasks by all, pending, or completed.
- Search tasks by title.
- Clear all completed tasks.
- Save tasks in the browser using `localStorage`.
- Responsive layout for desktop and mobile screens.

## Technologies

- Next.js (App Router)
- React
- JavaScript
- CSS
- Browser LocalStorage
